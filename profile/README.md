## ❓ FAQ

### Do I need to run it as Administrator?

No. This repository contains reference materials and does not include an executable or game-process attachment.

### Can antivirus software detect this ESP?

There is no functional ESP executable in this repository. Always review external downloads carefully and avoid untrusted third-party files.

### Is it compatible with Windows 11?

The reference materials can be viewed on Windows 11. They do not provide a functional Windows overlay.

### Does it reveal hidden enemies or resources?

No. The repository does not reveal hidden entities, read game memory, or provide live ESP functionality.

### Are third-party ESP overlays allowed in Guild Wars 2?

ArenaNet restricts third-party programs that provide an unintended or unfair advantage, including software that reads or displays information about game operation without authorization. Review the official policies before using any external overlay.
